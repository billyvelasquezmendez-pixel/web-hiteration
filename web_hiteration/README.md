# WEB_HITERATION

**Función semántica:** Continuidad estructural, reanclaje contextual y delimitación epistémica.

**Contenido:**
- Protocolos base (delta-engine, modelo-estados, p-drift)
- Diagnósticos de continuidad y asimetría
- Motor de reanclaje contextual

**Subcarpetas previstas:**
- `protocols/`
- `diagnostics/`
- `reanchoring/`

**Estado:** PROPOSED_NOT_CANONICAL

**Principio rector:** Preservación de coherencia estructural a través de ventanas de contexto.

**Nota de nomenclatura:**
Esta carpeta usa `web_hiteration` (guión bajo, una "t") como identificador
del namespace interno. Variantes rechazadas:
- `web-hitteration` (doble "t") — carpeta previa, en proceso de retiro
- `web-hiteration` (guión, una "t") — reservada al nombre del repositorio raíz
- `web_hiterarion` — typo, no usar

Cualquier aparición de una variante rechazada debe corregirse, no tratarse como ruta válida.
